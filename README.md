  <h3 align="left">Featured Project: Spartn</h3>
                                                                                                                                          
  ![App Screenshot](https://keano.cc/projects/gymniac/gymniacGithubBanner.png)
                                          
  #### Spartn — AI-Powered Fitness & Nutrition
                                                                                                                                          
  - Website → [spartn.app](https://spartn.app)
  - App Store → [Download on the App Store](https://apps.apple.com/us/app/gymniac/id6476600191)                                           
                                                            
  #### Features                                                                                                                           
                                                            
  - AI Smart Coach with personalized workout recommendations                                                                              
  - Cloud-based workout tracking with custom program builder
  - Comprehensive meal & macro tracking with HealthKit integration                                                                        
  - Trainer marketplace — connect with certified coaches    
  - Apple Watch + widget support              
  - Spartn Pro subscription with advanced analytics                                                                                       
                                                                                                                                          
  #### Tech Stack                                                                                                                         
                                                                                                                                          
  - **iOS**: SwiftUI, HealthKit, WatchKit, Firebase, Stripe                                                                               
  - **Backend**: Node.js/Express REST API, Next.js 15, Firebase Cloud Functions
  - **Infrastructure**: Firebase (Auth, Firestore, FCM, Remote Config), AWS (SES, EC2), Stripe Connect
